# 💎 GS Jewels — Jewellery E-Commerce Website

A full-stack jewellery e-commerce website built to provide a smooth online shopping experience with customer and admin features.

---

## ✨ Features

### 🛍️ Customer Features

- 🏠 Home page
- 💎 Jewellery catalogue
- 🔍 Product search
- 🏷️ Category filtering
- 💰 Price sorting
- 📋 Product details
- 🛒 Add to cart
- ❤️ Wishlist
- 👤 User registration and login
- 📦 Order history
- 📍 Delivery address
- ⭐ Product ratings and reviews
- 📊 Stock availability
- 📱 Responsive design

### 👑 Admin Features

- 🔐 Admin authentication
- 📊 Admin dashboard
- ➕ Add jewellery products
- ✏️ Edit products
- 🗑️ Delete products
- 📸 Product image upload
- 📦 Stock management
- 🏷️ Category management
- 📋 Order management
- 👥 Customer management
